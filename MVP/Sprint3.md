# 📌 MVP - Nexa Chemical

## 🎯 Objetivo do MVP
> Disponibilizar o Product Backlog e a Limpeza da Base de Dados.
- **Problema solucionado:** Ausência de uma visualização clara das organizações que compõe o ecossistema do PIT ( Parque técnologico de São José dos Campos ).
- **Hipótese:**  Uma tela inicial interativa, com visualizações gráficas e recursos de filtragem, facilitando a compreensão das informações.
- **Valor Entregue:** Disponibilização de dados limpos, tratados e organizados em um painel de Business Intelligence (BI).

---

## 📝 Descrição da Solução
> Desenvolvimento do product backlog e limpeza inicial da base de dados.   
- **Funcionalidades incluídas:**  
  - Desenvolvimento da estrutura inicial do Observatório em uma plataforma de BI.
  - Implementação da primeira visualização dos dados tratados.
  - Apresentação gráfica das informações para facilitar sua interpretação.
  - Disponibilização de filtros para exploração dos dados e análise das organizações que compõem o ecossistema.
- **Limitações:** Ausência de bases de dados externas complementares para ampliar a contextualização e a interpretação das informações.
- **Escopo reduzido:** Construção da tela principal do BI e à implementação das funcionalidades essenciais para a primeira versão do Observatório.

---

## 👥 Personas / Usuários-Alvo
- **Persona 1: Gestor de Políticas Públicas**  
  - Dores: Dificuldade de acessar e compreender informações estruturadas sobre o ecossistema devido à ausência de visualizações claras e intuitivas dos dados tratados.

- **Persona 2: Analista de Dados**  
  - Dores:  Necessidade de compreender a estrutura, os indicadores e os recursos de filtragem do BI para explorar os dados, identificar padrões e realizar análises do ecossistema.

## 📊 Critérios de Aceitação

- O MVP deve permitir que o usuário acesse e explore a tela inicial do Observatório, avaliando se as funcionalidades implementadas atendem às necessidades identificadas.
- Os dados apresentados devem estar organizados, tratados e disponíveis em visualizações que facilitem sua compreensão.
- O sistema deve disponibilizar filtros funcionais para a exploração das informações e a seleção das organizações que compõem o ecossistema.
- A aplicação dos filtros deve atualizar as visualizações correspondentes de maneira consistente com os critérios selecionados.
- A interface deve apresentar as informações de forma clara e intuitiva, permitindo que o usuário compreenda os principais elementos do painel.

---

## 📈 Métricas de Validação

* O MVP permite que o usuário analise o Product Backlog e explore os cenários propostos, possibilitando avaliar se as funcionalidades desenvolvidas atendem às necessidades e aos requisitos identificados. Além da disposição de uma base de dados limpa, centralizada e padronizada para melhores resultados.
