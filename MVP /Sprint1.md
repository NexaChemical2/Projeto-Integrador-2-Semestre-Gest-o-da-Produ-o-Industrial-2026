# 📌 MVP - Nexa Chemical

## 🎯 Objetivo do MVP
> Disponibilizar o Product Backlog e a Limpeza da Base de Dados.
- **Problema solucionado:** Falta de uma base de dados tratados e consolidados e o entendimento das necessidades do cliente.
- **Hipótese:** Product Backlog que permite a visualização das necessidades do cliente e limpeza da base de dados.
- **Valor Entregue:** Visualização do product backlog e limpeza dos dados organizados e tratados.

---

## 📝 Descrição da Solução
> Desenvolvimento do product backlog e limpeza inicial da base de dados.   
- **Funcionalidades incluídas:**  
  - Estrutura inicial do Product Backlog
  - Primeira visualização dos dados
  - Integração preliminar com as bases utilizadas.
- **Limitações:** Dados do Parque de Inovação Tecnológica de São José dos Campos (PIT) apresentam endereços incompletos e sem padronização, exigindo a consulta e integração de fontes externas para complementar as informações.
- **Escopo reduzido:** Realização do Tratamento de Dados.

---

## 👥 Personas / Usuários-Alvo
- **Persona 1: Gestor de Políticas Públicas**  
  - Dores: Ausência de dados acurados e estruturados.

- **Persona 2: Analista de Dados**  
  - Dores: Necessidade de entender a base inicial para evoluir as análises.

## 📊 Critérios de Aceitação

- O MVP deve permitir que o usuário visualize e analise o Product Backlog desenvolvido, possibilitando avaliar se as funcionalidades propostas atendem às suas necessidades e aos requisitos identificados.
- O sistema deve disponibilizar bases de dados centralizadas, limpas e padronizadas, garantindo a confiabilidade das informações e contribuindo para o funcionamento eficiente e o desenvolvimento do observatório.
- Métricas coletadas: tempo de resposta, uso de filtros, frequência de comparações, visualizações e exportações, e tempo médio de uso.

---

## 📈 Métricas de Validação

* O MVP permite que o usuário analise o Product Backlog e explore os cenários propostos, possibilitando avaliar se as funcionalidades desenvolvidas atendem às necessidades e aos requisitos identificados. Além da disposição de uma base de dados limpa, centralizada e padronizada para melhores resultados.
